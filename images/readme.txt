This folder is for product chart images. You can add your own chart screenshots or trading images here for each product. Example usage:
- images/ninjatrader1.png
- images/tradingview1.png

Update the product objects in index.html to use local image paths (e.g., 'images/ninjatrader1.png') for best performance and reliability.

Currently, product images use Unsplash URLs. Replace with your own images for a custom look.
